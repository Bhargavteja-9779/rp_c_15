# Supplementary material: guide

Supplementary Notes S1–S8 follow in order. Tables and figures that appear inside these notes are numbered Table S-1, S-2, … and Fig. S-1, S-2, …; the complete machine-generated result tables are separate files, cited as "supplementary table S1" to "S24" (for example S6b, the lot-level tests without repeated scans). Analyses marked exploratory or post hoc were not pre-specified (main text, Section 3.8).
