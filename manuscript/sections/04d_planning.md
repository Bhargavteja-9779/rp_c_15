# 15. Planning the reference budget

Fig. 13 compares the width planned from the source seasons (Section 4.9) with the width realised on the lots of the target season, for the five target seasons, three predictors, five values of $m$ and both variants.

![Fig. 13. Reference-budget planning. (a) Interval width planned from past lots against the mean width realised on the lots of the following season; each point is one target season, predictor, number of reference samples and variant. (b) Planned and realised budget curves for PLS, averaged over target seasons.](figures/fig13_planning.png){width=6.3in}

The planned width is a usable forecast. Over all {{len(r.plan)}} combinations the median absolute relative difference between realised and planned width is {{f"{100*r.plan.rel_error.abs().median():.0f}"}} %, and the mean difference is {{f"{100*r.plan.rel_error.mean():.0f}"}} %. For PLS and LightGBM the median absolute difference is {{f"{100*r.plan[r.plan.model=='pls'].rel_error.abs().median():.0f}"}} % and {{f"{100*r.plan[r.plan.model=='gbm'].rel_error.abs().median():.0f}"}} %; for the CNN it is {{f"{100*r.plan[r.plan.model=='cnn'].rel_error.abs().median():.0f}"}} %. By target season the mean difference ranges from {{f"{100*r.plan.groupby('target').rel_error.mean().min():.0f}"}} % to {{f"{100*r.plan.groupby('target').rel_error.mean().max():.0f}"}} %: the forecast is too wide for 2017, when the calibration rested on two source seasons whose season-held-out models were weak, and within {{f"{100*r.plan[r.plan.target>2017].groupby('target').rel_error.mean().abs().max():.0f}"}} % for the four later seasons (supplementary table S15). The shape of the curve is reproduced (Fig. 13b): most of the reduction in width is obtained with the first five reference samples, and beyond ten both curves flatten. The largest deviations in Fig. 13a are the CNN in 2017, where the planned width is well above the realised one. A grower or packhouse can therefore read the cost of a given precision from the calibration set before the season, separately for the average-coverage interval and for the lot-level assurance.
